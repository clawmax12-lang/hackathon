# Monterra MVP

A responsive one-screen product prototype for turning a photo of a flat-pack product into a clear setup guide.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL. Use **Add photo → Try a sample package** to walk through the full interaction without uploading an image.

## Included in this design pass

- Photo upload, camera capture, drag-and-drop, and attachment previews
- Mobile and desktop navigation
- Expandable, accessible generation progress
- Product match confirmation
- Interactive video result card with written steps
- Sticky follow-up composer
- Keyboard and reduced-motion support

The product recognition and video generation are intentionally represented as prototype states; this repository contains no AI backend.
